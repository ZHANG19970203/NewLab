# NewLab · 动小学人体运动学虚拟实验室

[进入在线练习](https://zhang19970203.github.io/NewLab/)　·　[下载 Windows 完整版](https://github.com/ZHANG19970203/NewLab/releases/tag/teacher-dashboard-20261124)

在线版提供浏览器内的课程练习，保存在当前浏览器的学习记录仅在该设备可用。GitHub Pages 提供静态托管，班级数据汇总与教师认证由完整版的 Python 教学服务处理。

Windows 版解压后运行“打开虚拟实验室.cmd”或“打开教师端.cmd”。教师用自己的账户查看登记学生的成绩、累计使用与完成曲线、对话及问题反馈，按学号查看历次进度，并导出 Excel。正式学习数据保存在教学服务的数据库中。

`docs/` 是公开练习网站，`site/` 是支持教师端的教学应用源码。素材许可见 `site/licenses/`。
